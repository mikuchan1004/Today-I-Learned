### 데이터 검색과 필터링 (기본기)

* **LIKE 와일드카드** : 특정 문자가 포함된 데이터를 찾을 때 사용. `%`은 '모든 문자(길이 상관 없음)', `_`은 '딱 한 글자'를 의미.

  * 예) `WHERE name LIKE '김%'` : 김으로 시작하는 모든 사람

* **널(NULL) 값 검색** : 값이 비어있는지 확인할 때 사용. `=` 기호르는 못 찾으니까 무조건 `IS NULL`이나 `IS NOT NULL`을 써야한다.

바보같이 `= NULL`이라고 쓰지 말자.

----

### 함수와 조건문 (알아두면 편함)

* **일반 함수** : 문자, 숫자, 날짜 등을 다듬을 때 사용. `SUBSTR`(문자 자르기), `ROUND`(반올림), `SYSDATE`(현재 날짜) 같은 것들이 있다.

* **집계 함수** : 여러 행의 데이터를 하나로 요약해주는 함수. `COUNT`(개수), `SUM`(합계), `AVG`(평균), `MAX`(최댓값), `MIN`(최솟값).

* **CASE문** : SQL 안에서 쓰는 `IF-THEN-ELSE` 같은 조건문. "이 조건일 때는 A, 저 조건일 때는 B" 식으로 값을 출력하고 싶을 때 쓰면 된다.

----

### 그룹화 (끼리끼리 모아보자!)

* **GROUP BY절** : 같은 값을 가진 데이터끼리 그룹을 지어주는 역할. 주로 '집계 함수'랑 짝꿍으로 쓰임. (예: 부서별 평균 급여)

* **HAVING절** : `GROUP BY`로 묶은 그룹에 조건을 걸 때 사용. `WHERE`절이랑 헷갈리지 말자.

**주의) `WHERE`는 그룹으로 묶기 **전**에 필터링하는 거고, `HAVING`은 묶은 **후**에 필터링하는 거니까 명심하자.**

----

### 데이터 합치기와 확장

|개념|설명|
|:---|:---|
|**집합 연산자**| 위아래로 쿼리 결과를 덩어리째 합치는 것. 대표적으로 `UNION`(중복 제거), `UNION ALL`(중복 포함)이 있는데. 열의 개수와 타입이 똑같아야 쓸 수 있다|
|**서브 쿼리**| 쿼리문 안에 또 다른 쿼리문이 들어가는 것. 괄호`()`로 묶어서 쓰고, 메인 쿼리를 도와주는 착한 조수 역할을 한다.|
|**JOIN(조인)**| 집합 연산자가 위아래로 합친다면, 조인은 **양옆으로** 테이블을 이어 붙이는 것. 공통된 컬럼을 기준으로 데이터를 연결한다. `INNER JOIN`(교집합), `LEFT JOIN`(왼쪽 기준 다 가져오기)이 제일 많이 쓰임|

### GROUP BY와 HAVING절을 쓰는 간단한 예시 코드 

``` sql

-- 부서별 평균 급여 구하기

SELECT 
    부서명, 
    COUNT(직원ID) AS 직원수, 
    AVG(급여) AS 평균급여
FROM 직원
WHERE 입사일 >= '2023-01-01'     -- 1. WHERE절: 일단 2023년 이후 입사자만 필터링! (그룹화 전)
GROUP BY 부서명                 -- 2. GROUP BY절: 남은 직원들을 부서명 기준으로 끼리끼리 묶어!
HAVING AVG(급여) >= 5000000;    -- 3. HAVING절: 묶은 부서들 중에서 평균 급여가 500만 원 이상인 그룹만 통과!
```

### JOIN 예시 코드

``` sql

-- INNER JOIN (딱 맞는 짝만 찾기)
-- 양쪽 테이블에 모두 데이터가 있는, 즉 '교집합'만 쏙 빼오는 것

SELECT 
    A.이름, 
    B.부서명
FROM 직원 A
INNER JOIN 부서 B 
    ON A.부서ID = B.부서ID;  -- 여기서 두 테이블을 연결할 '열쇠'를 지정해 주는 거야!
```

``` sql

-- LEFT JOIN (왼쪽은 무조건 다 챙기기)
-- 기준이 되는 왼쪽 테이블(FROM절에 쓴 테이블)의 데이터는 무조건 100% 가져오고
-- 오른쪽 테이블은 짝이 맞는것만 가져온다. 짝이 없으면? 그냥 빈칸(NULL)로 두는 것.

SELECT 
    A.이름, 
    B.부서명
FROM 직원 A
LEFT JOIN 부서 B 
    ON A.부서ID = B.부서ID;
```

**JOIN 요약**

|종류|특징|비유하자면?|
|:---|:---|:---|
|**INNER JOIN**|양쪽 다 있는 것만|"부서 있는 직원만 나와!"|
|**LEFT JOIN**|왼쪽 전부 + 오른쪽은 맞는 것만|"직원들 다 모여! 부서 없는 애들은 빈칸으로 냅두고!"|
|**RIGHT JOIN**|오른쪽 전부 + 왼쪽은 맞는 것만|(LEFT랑 방향만 반대이라서 LEFT를 더 많이 사용)|

### 서브 쿼리 예시 코드 

``` sql

-- 서브 쿼리 : 회사 평균 급여보다 많이 받는 사람 찾기
-- '우리 회사 직원들의 평균 급여를 먼저 구하고, 그 평균보다 급여를 많이 받는 잘나가는 사람들'을 찾고 싶다면 이렇게 짜면 된다.

SELECT 
    이름, 
    급여
FROM 직원
WHERE 급여 > (
    SELECT AVG(급여) FROM 직원  -- ⬅️ 여기가 서브 쿼리야! 괄호 필수!
);
```

* 쿼리문이 실행될 때는 **항상 괄호 안의 '서브 쿼리'부터 먼저 실행** 된다는 것을 기억하자.
