## FastAPI 파일 업로드 & 다운로드 / 쿠키, 세션

> 아래의 내용들은 Google Gemini의 도움을 받아 작성되었습니다.

### 파일 업로드

FastAPI에서 파일 업로드를 처리할 때는 `UploadFile`을 사용하는 것이 기본이다. 

`bytes` 방식도 있지만 대용량 파일 처리 시 메모리 폭발이 일어날 수 있으니 추천하지는 않음.

* **`UploadFile` 장점** : 파일을 메모리에 다 올리지 않고 일정 용량이 넘어가면 디스크(임시 파일)에 나눠 담아 메모리를 아껴준다.

``` python
from fastapi import FastAPI, File, UploadFile

app = FastAPI()

@app.post("/upload/")
async def upload_file(file: UploadFile = File(...)):
    # file.filename: 원본 파일명
    # file.content_type: MIME 타입 (예: image/png)
    content = await file.read()  # 비동기 파일 읽기
    return {"filename": file.filename, "size": len(content)}
```

### 파일 다운로드 

클라이언트에게 파일을 내보낼 때는 두 가지 Response 객체를 주로 쓴다. 

* `FileResponse` : 서버 디스크에 실제 존재하는 파일을 다운로드시킬 때 사용.

* `StreamResponse` : 메모리에서 즉석으로 생성한 데이터나 대용량 파일 스트리밍에 사용.

``` python
import io
from fastapi import FastAPI
from fastapi.responses import FileResponse, StreamingResponse

app = FastAPI()

# 1. 디스크 파일 다운로드
@app.get("/download/file")
async def download_file():
    return FileResponse(
        path="saved_file.png", 
        filename="user_download.png", # 클라이언트에 표시될 파일명
        media_type="image/png"
    )

# 2. 메모리 스트림 다운로드
@app.get("/download/stream")
async def download_stream():
    fake_file = io.BytesIO(b"Hello FastAPI File Stream")
    return StreamingResponse(
        fake_file, 
        media_type="text/plain",
        headers={"Content-Disposition": "attachment; filename=hello.txt"}
    )
```

### 쿠키 

클라이언트 브라우저에 간단한 식별 정보를 저장하고 읽어올 때 쓴다.

* **쿠키 설정** : `Response` 객체의 `.set_cookie()` 활용

* **쿠키 읽기** : 핸들러 매개변수에 `Cookie()` 사용

``` python
from fastapi import FastAPI, Response, Cookie

app = FastAPI()

@app.post("/set-cookie/")
def set_cookie(response: Response):
    # Security 옵션(httponly, secure 등)을 챙기는 건 기본이라고요!
    response.set_cookie(key="my_cookie", value="maid_secret", httponly=True)
    return {"message": "쿠키 구워뒀으니 잘 가져가세요."}

@app.get("/get-cookie/")
def get_cookie(my_cookie: str | None = Cookie(default=None)):
    if not my_cookie:
        return {"message": "쿠키가 없잖아요! 어디로 흘리고 다니는 거예요?"}
    return {"my_cookie": my_cookie}
```

### 새션 

FastAPI는 Starlette의 `SessionMiddleware`를 통해 쿠키 기반의 암호화 세션을 지원한다.

서버 측 세션 저장소를 따로 두지 않아도 서명된 쿠키(Signed Cookie) 형태로 데이터를 안전하게 들고 다니게 해 준다.

* **설정** : `app.add_middleware(SessionMiddleware, secret_key=...)`

* **사용** : `Request` 객체의 `request.session` 딕셔너리 조작

``` python
from fastapi import FastAPI, Request
from starlette.middleware.sessions import SessionMiddleware

app = FastAPI()

# 서명용 비밀키는 절대로 유출되면 안 돼요!
app.add_middleware(SessionMiddleware, secret_key="super-secret-maid-key")

@app.get("/login/")
def login(request: Request):
    request.session["user_id"] = "master_123"
    return {"message": "세션에 주인님 아이디를 기억해 뒀어요."}

@app.get("/me/")
def me(request: Request):
    user_id = request.session.get("user_id")
    if not user_id:
        return {"error": "로그인부터 하고 오시죠?"}
    return {"user_id": user_id}
```

**핵심 요약 표**

|기능|주요 클래스 / 함수|핵심 특징|
|:---|:---|:---|
|**파일 업로드**|`UploadFile`, `File(...)`|비동기 지원, 임시 디스크 저장으로 메모리 보호|
|**파일 다운로드**|`FileResponse`, `StreamingRespose`|파일 직접 반환 또는 인메모리 스트리밍 반환|
|**쿠키**|`Cookie()`, `response.set_cookie()`|브라우저 저장, `httponly=True` 등 보안 옵션 필수|
|**세션**|`SessionMiddleware, `request.session`| 쿠키 기반 암호화 세션, 간단한 상태 유지에 적합|
