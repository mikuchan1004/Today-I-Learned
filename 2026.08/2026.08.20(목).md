## FastAPI if문, 반복문, 필터, 매크로

> 이 내용들은 Google Gemini의 도움을 받아 작성하였습니다.

**if문 (조건문)**

* 조건에 따라 특정 HTML 요소의 표시 여부를 제어.

* `{% if %}`, `{% else %}`. `{% endif %}` 구문을 사용

``` html
{% if user.is_admin %}
    <p>관리자 전용 페이지입니다.</p>
{% elif user.is_active %}
    <p>환영합니다, {{ user.name }}님!</p>
{% else %}
    <p>로그인이 필요합니다.</p>
{% endif %}
```

**반복문 (for문)**

* 리스트나 딕셔너리 데이터를 순회하여 반복 출력.

* `loop.index`(1부터 시작하는 인덱스), `loop.first`, `loop.last`등의 내부 변수를 활용할 수 있다.

``` html
<ul>
{% for item in items %}
    <li>{{ loop.index }}번 상품: {{ item.name }}</li>
{% else %}
    <li>등록된 상품이 없습니다.</li>
{% endfor %}
</ul>
```

**필터**

* 파이프(`|`) 기호를 사용해 출력할 변수 데이터를 가공.

* `{{ name | upper}}` (대문자 변환), `{{text | default('기본값')}}` 처럼 내장 필터를 쓰거나,

FastAPI에서 백엔드 함수를 직접 등록해 사용할 수 있다.

``` html
# FastAPI(Python) 측 커스텀 필터 등록
def format_price(val):
    return f"{val:,}원"

templates.env.filters["price_format"] = format_price

<!-- Jinja2 템플릿 측 사용 -->
<p>가격: {{ product.price | price_format }}</p>
```

**매크로(Macro)** 

* 자주 쓰이는 HTML 컴포턴트를 함수처럼 정의해서 재사용.

* `{% macro 매크로명(파라미터) %}`으로 정의하고, 필요할 때 호출하여 사용.

``` html
<!-- 매크로 정의 -->
{% macro render_input(name, type='text', placeholder='') %}
    <input type="{{ type }}" name="{{ name }}" placeholder="{{ placeholder }}" class="form-control">
{% endmacro %}

<!-- 매크로 사용 -->
<form>
    {{ render_input('username', placeholder='아이디를 입력하세요') }}
    {{ render_input('password', type='password', placeholder='비밀번호') }}
</form>
```
