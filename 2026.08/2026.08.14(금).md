## FastAPI pydantic

**pydantic의 핵심 역할**

* **자동 데이터 검증(Data Validation)** : 클라이언트가 보낸 JSON 요청 데이터의 타입, 필수 여부, 범위 등을 자동으로 검사해서

  규격에 맞지않으면 `422 Unprocessable Entry` 에러를 자동으로 반환한다. 

* **데이터 직렬화(Serialization)** : 파이썬 객체나 딕셔너리를 클라이언트가 읽을 수 있는 JSON 포맷으로 자동 변환.

* **자동 API 문서화(Swagger UI)** : 작성한 Pydantic 스키마를 기반으로 `/docs` 경로에 대화형 OpenAPI 문서 사양이 자동으로 생성.

**주요 기능 및 사용법**

* **`BaseModel`상속** : 데이터 구조를 정의할 때 Pydantic의 `BaseModel`을 상속받아 파이썬 타입 힌트(Type Hint)와 함께 선언.

* **`Field` 세부 설정** : `Field()`를 사용해 데이터의 최장/최단 길이(`min_length`, `max_length`), 숫자 범위(`gt`,`le`),

  설명(`description`), 기본값 등을 지정.

* **`response_model`매개변수** : 라우터 데코레이터에 지정하여, 클라이언트에 응답할 때 비밀번호 같은 민감한 필드를 알아서 제외하거나 형식을 제한함.

**실제 활용 코드 예시**

``` python
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()

# 1. Pydantic 스키마 정의
class Item(BaseModel):
    name: str = Field(..., min_length=1, description="상품 이름")
    price: float = Field(..., gt=0, description="0보다 큰 가격")
    is_offer: bool | None = None

# 2. FastAPI 라우터에서 요청 바디로 활용
@app.post("/items/", response_model=Item)
def create_item(item: Item):
    return item
```
