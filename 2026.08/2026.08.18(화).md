## FastAPI 정리, 경로 변수

### FastAPI

* 경량화된 웹 프레임워크

* 라이브러리 library

  * 클래스, 함수(메소드), 변수들의 집합
 
  * 보통 같은 목적을 가진 코드의 집합
 
* 프레임워크 framework

  * 라이브러리를 특별하게 부르는 말
 
  * 스스로 클래스를 생성해서 사용할 수 있는 능력이 있는 라이브러리
 
### CMD 명령어 

* dir : 디렉토리 즉 폴더 안의 내용 보기

* cd : 폴더 이동

* activate : 파이썬 가상환경 활성화

### 실행방법 

**방법 1**

``` python
# api.py
from fastapi import FastAPI

app = FastAPI()

@app.get('/')
def welcome() :
    return {
        "message": "Hello World"
    }
```

* cmd에서 명령어를 입력하는 것을 권장 (파워쉘에선 보안 문제로 막혀서 사용이 어려움)

* uvicorn api:app --port:8000 --reload

  * uvicorn : FastAPI를 실행시켜 주는 모델
 
  * api : `api.py` 즉 파일명
 
  * app : FastAPI 모듈을 담은 변수
 
  * --port : 포트 지정 (기본값 : 8000)
 
  * --reload : `api.py` 파일이 변경될때마다 재시작
 
**방법 2**

``` python
# api.py
from fastapi import FastAPI

app = FastAPI()

@app.get('/')
def welcome() :
    return {
        "message": "Hello World"
    }

if __name__ == "__main__":
    import uvicorn
    uvicorn.run("api:app", port=8000, reload=True)
```

* python api.py

* 방법 1과 방법 2는 동일한 효과를 내니까 편한걸 쓰면 된다.

>`__name__`
> * 이 모듈을 python으로 직접 실행한 경우 결과 값 : `__main__`
> * 이 모듈을 다른 곳에서 import 하는 경우 결과 값 : 파일명

### CORS

* 크로스 도메인 문제 발생

* 서로 도메인이나 IP가 다른 경우 ajax등을 통해 접근하지 못하게 하는 보안 기술

* 서버 측에서 CORS 허용하는 방법

``` python
from fastapi.middleware.cors import CORSMiddleware
app.add_middleware(
    CORSMiddleware,
    allow_origins = ["*"],
    allow_methods = ["*"],
    allow_headers = ["*"]
)
```

### REST

* REST, RSETful, REST api 라고도 한다

* 접근 방식(메서드)를 get, post, put, delete의 용도에 맞게 사용하자는 운동

  * get : Read : select
 
  * post : Create : insert
 
  * put : Update : update
 
  * delete : Delete : delete
 
* 같은 주소에 메서드만 다르게 활용할 수 있는 장점이 생긴다

> 실무에서는
> 백엔드에서 서버를 다뤄 봤는가? 의 의미로 많이 사용된다.

### HTML 응답 코드 

* 2xx : 200번 대

  * 성공
 
* 3xx

  * 다른 곳으로 가라는 의미 (리다이렉트)
 
  * 착신 전환 느낌
 
* 4xx : 사용자 실수

  * 404 : Page Not Found : 주소 없음
 
  * 405 : Method Not Allowed
 
    * 지원하지 않는 방식(메서드)
   
    * get만 받기로 되어 있는데 post로 보낸 경우 등
   
  * 422 : Unprocessable Content
 
    * 전달인자가 안 맞아서 못 들어감
   
    * 필수 값 없음
   
    * 보통은 400 코드로 오는데 FastAPI는 422로 옴
   
  * 400 : Bad Request
 
    * 전달인자가 안 맞아서 못 들어감
   
    * 필수 값 없음
   
* 5xx : 서버 오류

### 전달 인자 

* 기본 메서드는 무조건 전달인자가 있어야 동작한다는 원칙은 유지된다

* 기본값이 있는 경우 생략이 가능했다.

``` python
@todo_router.get('/todo/param')
async def todoParamGet(id : int, item:str = "") -> dict :
    print(id, item)
    return {
        "id": id,
        "item": item
    }
```

* id의 제약 조건

  * 기본 값이 없으므로 필수 값
 
    * 없으면 422 코드
   
  * int로 타입을 지정했다.
 
    * int로 변환되지 않는 경우 422 코드
   
* item의 제약 조건

  * 기본 값이 있어서 필수 값 아님
 
    * 전달하지 않아도 ""로 받아진다.
   
  * 모든 자료는 string으로 받을 수 있다.

### 리턴 타입 

``` python
@todo_router.get('/todo/param')
def todoParamGet(id : int, item:str = "") -> dict :
    print(id, item)
    return {
        "id": id,
        "item": item
    }
```

* `->dict` 이것에 대한 이야기 

* return 하는 자료형의 타입을 검증해준다.

  * 개발자의 실수를 줄여준다.

### Request 

* 클라이언트의 요청 사항이 모두 들어 있는 객체

**사용법**

``` python
from fastapi import APIRouter, Form, Request

@todo_router.get('/todo/param2')
@todo_router.post('/todo/param2')
@todo_router.put('/todo/param2')
@todo_router.delete('/todo/param2')
async def todoParam(req : Request) -> dict :
    if req.method == 'GET':
        data = req.query_params
    else :
        data = await req.form()

    id = data.get('id')
    item = data.get('item')
    print(id, item, req.method)

    return {
        "id": id,
        "item": item
    }
```

### 쓸 만한 것들 

* methon : HTTP Method

  * 대문자로 된 GET, POST, PUT, DELETE
 
* 파라메터 가져오기

  * GET

    * query_params
  
    * 딕셔너리로 반환해 줌

  * GET 이외
 
    * await req.form()
 
    * 딕셔너리로 반환해 줌
    
* client
 
  * host : 접속 ip
   
  * port : 접속 port
   
* url
 
  * 접속 전체 주소
   
* path
 
  * 포트 이후 ? 앞까지의 주소
   
  * 즉 요청 경로

  * 예를 들어
 
    * 접속 주소가 localhost:8000/a/b?id=1234
   
    * path의 값 : /a/b
   
* headers

  * 클라이언트의 요청 헤더 가져오기
 
  * 딕셔너리로 반환해 줌
 
* cookie

  * 쿠키들을 딕셔너리로 돌려줌
 
* json()

  * await.req.json()
 
  * post로 보낸 json 받아오기
