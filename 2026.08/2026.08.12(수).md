## FastAPI

**FastAPI**는 파이썬 기반으로 고성능 API를 빠르게 구축하기 위해 만들어진 **현대적인 웹 프레임워크**.

## FastAPI의 장점 

* **이름 그대로 미친 듯이 빠르다** : `Starlette`과 `Pydantic`이라는 탄탄한 라이브러리 기반이라, NodeJS나 Go 언어와 비견될 정도로 파이썬 프레임워크 중 최고 수준의 성능을 자랑한다. 

* **API 문서를 알아서 만들어준다** : 코드를 작성하고 실행한 뒤 `/docs` 경로로 들어가기만 하면 Swagger UI 기반의 **대화형 API 문서가 자동으로 생성된다**

* **데이터 검증이 자동으로 된다** : 파이썬의 표준 타입 힌트만 적어두면, 들어오는 요청 데이터가 올바른 형식인지 자동으로 검사하고 에러 메시지까지 친절하게 반환해준다.

* **비동기(async/await) 완벽 지원** : DB 조회나 외부 API 호출처럼 대기 시간이 발생하는 작업을 비동기로 처리해서 서버 리소스를 극대화할 수 있다.

## FastAPI 예시 코드 

``` python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def welcome() -> dict:
    return {
        "message" : "Hello World"
    }
```

## FastAPI 사용법 

1. 파이썬 가상 환경 생성

  * 가상 환경을 만드는 이유 : 프로젝트 간의 패키지(라이브러리) 버전 충돌을 방지하기 위해

  ``` cmd
  c:\code\todos> mkdir todos && cd todos
  c:\code\todos> python -m venv venv
  ```

2. 가상 환경 활성화

  ``` cmd
  c:\code\todos> venu\Scripts\activate
  ```

3. pip가 설치되어 있는지 확인해보기

  * pip는 파이썬을 설치할 때 함께 설치되기 때문에 생략해도 문제 없음.

  ``` cmd
  c:\code\todos> python -m pip list
  ```

4. fastapi와 uvicorn 설치하기

  ``` cmd
  c:\code\todos> pip install fastapi uvicorn
  ```

5. api.py 파일 생성 및 코드 작성

  ``` python
  # 1. FastAPI 프레임워크에서 핵심이 되는 FastAPI 클래스를 불러온다 
  from fastapi import FastAPI

  # 2. FastAPI 애플리케이션 객체(인스턴스)를 실행
  # 이 'app' 변수가 전체 웹 서버의 중심이 되어 요청과 라우팅을 총괄
  app = FastAPI()

  # 3. HTTP GET 요청을 하는 경로 동작 데코레이터(Path Operation Decorator).
  # 클라이언트가 웹사이트의 기본 루트 경로("/")로 접속했을 때, 바로 아래의 함수를 실행.
  @app.get("/")
  async def welcome() -> dict:
  """
  4. 비동기(async) 방식으로 동잓하는 welcome 함수.
   '-> dict'는 이 함수가 파이썬 딕셔너리(dict) 타입을 반환한다는 것을 명시하는 타입 힌트.
  """
      # 5. 사용자에게 전달할 응답(Response) 데이터를 반환.
      # FastAPI는 파이썬 딕셔너리를 자동으로 JSON 형식({"message" : "Hello World"})으로 변환해서 응답해줌.
      return {
          "message" : "Hello World"
      }
  ```

6. uvicorn을 써서 애플리케이션을 시작해보자.

  ``` cmd
  c:\code\todos> uvicorn api:app --port 8000 --reload
  ```
