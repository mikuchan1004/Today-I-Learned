## 데이터베이스 INSERT문, UPDATE문, DELETE문, SQL 활용

> 이 내용들은 Google Gemini의 도움을 받아 작성하였음을 밝힙니다.

### SQL DML (데이터 조작어) 정리

1. 데이터 추가 : `INSERT`

새로운 행을 테이블에 집어넣는 명령.

``` sql
-- 1) 특정 컬럼만 지정해서 값 넣기
INSERT INTO EMP (EMPNO, ENAME, SAL, DEPTNO)
VALUES (9000, 'MEID', 3000, 10);

-- 2) 모든 컬럼의 값을 순서대로 다 넣을 때 (컬럼명 생략 가능)
INSERT INTO EMP
VALUES(9001, 'MASTER', 'MANAGER', 7839, SYSDATE, 4000, NULL, 10);

-- 3) [응용] 다른 테이블의 데이터를 조회해서 한 번에 대량으로 넣기
INSERT INTO EMP_BAK
SELECT * FROM EMP WHERE DEPTNO = 10;
```

2. 데이터 수정 : `UPDATE`

이미 존재하는 데이터를 원하는 값으로 바꿀 때 사용.

``` sql
-- 기본 문법 : SET 뒤에 바꿀 값, WHERE 뒤에 대상 지정
UPDATE EMP
SET SAL = 3500, JOB = 'SENIOR'
WHERE ENAME = 'MAID';
```

**주의) `UPDATE`문에서 `WHERE`절을 빼먹으면 테이블 전체 데이터의 급여가 3500으로 다 덮어씌어지니까 `WHERE`절을 썼는지 두 번, 세 번 확인하자**

3. 데이터 삭제 : `DELETE`

필요없는 행을 테이블에서 지워버릴 때 사용

``` sql
-- 특정 조건을 만족하는 데이터만 삭제

DELETE FROM EMP
WHERE ENAME = 'MEID';
```

**주의)이것도 `WHERE`절을 안 쓰면 테이블 안의 데이터가 싹 다 지워지니까 조심해서 쓰자**

----

### SQL 활용

1. **`WHERE`절은 생명선!!**

  * `SELECT`에서 `WHERE`는 단순 필터링이지만, `UPDATE`와 `DELETE`에서의 `WHERE`는 **데이터 손상을 막아주는 방화벽**!

2. **서브쿼리와의 결합(고급 활용)**

  * `UPDATE`나 `DELETE` 조건절 안에 `SELECT`문을 넣어서 훨씬 정교하게 지우거나 수정할 수 있다.

  * 예: "부서 평균 급여마다 적게 받는 사람의 급여를 인상하라" 같은 문제에서 서브쿼리가 쓰이는 것!

3. **트랜잭션(Transaction)유의**

  * `INSERT`, `UPDATE`, `DELETE`를 실행했다고 끝이 아니고. 진짜 데이터베이스에 반영하려면 `COMMIT`, 잘못 지웠을 때 되돌리려면 `ROLLBACK`을 해야 한다는 거 잊지 말자
