## FastAPI 응답 모델과 오류 처리, Jinja

> 아래 내용들은 Google Gemini의 도움을 받아 정리하였음을 밝힙니다

**FastAPI 응답 모델(Response Model)**

클라이언트에게 반환할 데이터의 구조를 제한하고 검증하는 기능.

민감한 정보(비밀번호 등)가 실수로 유출되는 것을 막아주고, Swagger API 문서에 반환 타입을 자동으로 명시해 줌.

* **기본 사용법** : 데코레이터에 `response_model`을 지정.

``` python
from pydantic import BaseModel, EmailStr
from fastapi import FastAPI

app = FastAPI()

# 요청 시 받을 데이터 모델
class UserIn(BaseModel):
    username: str
    password: str
    email: EmailStr

# 응답 시 나갈 데이터 모델 (password 제외)
class UserOut(BaseModel):
    username: str
    email: EmailStr

@app.post("/users/", response_model=UserOut)
async def create_user(user: UserIn):
    # UserIn 데이터를 그대로 반환해도 UserOut 스키마에 맞춰 password는 자동으로 필터링됩니다!
    return user
```

* **유용한 응답 모델 옵션**

  * `response_model_exclude_unset=True` : 기본값이 설정되어 있고 클라이언트가 요청에서 설정하지 않은 필드는 응답에서 제외.
 
  * `response_model_exclude={"password"}` : 특정 필드를 직접 지정하여 제외함
 
  * `response_model_include={"username", "email"}` : 특정 필드만 포함시킴.

**오류 처리(Error Handling)** 

클라이언트에게 적절한 HTTP 상태 코드와 에러 메시지를 전달할 때 사용.

* **HTTPException 사용** : 가장 기본적인 예외 발생 방식.

``` python
from fastapi import FastAPI, HTTPException, status

app = FastAPI()

items = {"foo": "The Foo Item"}

@app.get("/items/{item_id}")
async def read_item(item_id: str):
    if item_id not in items:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="아이템을 찾을 수 없단 말이에요!",
            headers={"X-Error": "Item not found"}
        )
    return {"item": items[item_id]}
```

* **커스텀 예외 처리기(Custom Exception Handler)** : 전역에서 특정 예외를 포착하여 일관된 JSON 형식으로 응답할 때 작성.

``` python
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse

class ItemNotFoundException(Exception):
    def __init__(self, name: str):
        self.name = name

app = FastAPI()

@app.exception_handler(ItemNotFoundException)
async def item_not_found_exception_handler(request: Request, exc: ItemNotFoundException):
    return JSONResponse(
        status_code=404,
        content={"message": f"주인님, '{exc.name}' 아이템은 존재하지 않아요!"},
    )

@app.get("/custom-item/{name}")
async def read_custom_item(name: str):
    if name != "master":
        raise ItemNotFoundException(name=name)
    return {"item": "master"}
```

**Jinja 템플릿 연동**

HTML 페이지를 서버쪽에서 동적으로 렌더링할 때 사용하며, `jinja2` 패키지 설치가 필요. (`pip install jinja2`)

* **FastAPI 연동 기본 코드**

``` python
from fastapi import FastAPI, Request
from fastapi.responses import HTMLResponse
from fastapi.templating import Jinja2Templates

app = FastAPI()

# 'templates' 디렉터리 지정
templates = Jinja2Templates(directory="templates")

@app.get("/hello/{name}", response_class=HTMLResponse)
async def read_item(request: Request, name: str):
    # TemplateResponse 생성 시 반드시 request 객체를 context에 넘겨주어야 합니다!
    return templates.TemplateResponse(
        request=request, 
        name="hello.html", 
        context={"name": name, "items": ["사과", "바나나", "포도"]}
    )
```

* **Jinja 주요 문법 요약**

|구문|설명|예시|
|:---|:---|:---|
|`{{ ... }}`| 변수 출력 및 표현식 평가 | `<h1>안녕하세요, {{name}}님!</h1>`|
|`{% ... %}`| 제어문 (조건문, 반복문, 상속) | `{% for item in items %}<li>{{item}}</li>{% endfor %}`|
|`{# ... #}` | 주석 (클라이언트 HTML에 노출 안 됨) | `{# 이 부분은 주석입니다. #}`|
|`{% extends %}` | 템플릿 상속 | `{% extends "base.html" %}`|
