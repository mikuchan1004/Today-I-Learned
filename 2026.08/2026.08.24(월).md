## FastAPI 데이터베이스 연결(SQLite, pymysql, sqlmodel)

### SQLite

* import sqlite3로 내장된 모듈을 불러와서 사용한다.

#### 연결 

``` python
sqlite.connect('DB 파일명')
```

* 파일이 없으면 새로 만들고 파일이 있으면 재활용한다.

* `cursor()`로 실제 연결 객체를 가져온다.

#### SQL문 준비

* 기본적으로 string으로 SQL문을 준비한다. 

* 전달인자가 있는 경우 변수값에 해당하는 곳에 placeholder로 물음표를 적고,

  두번째 전달인자로 물음표 순서대로 튜플로 값을 지정한다.

* SQL Injection 공격을 방지한다.

#### 실행 

``` python
cursor.exeute(SQL문, [값이 있는 튜플])
```

* SQL에 물음표가 있는 경우 튜플로 물음표의 개수와 같은 양의 값을 전달해야 한다.

#### 결과 확인 

- SELECT

* `cursor.fetchall()`

  * 모든 값을 리스트로 가져온다.
 
  * 한 줄은 튜플로 가져온다. 즉, 튜플로 이루어진 리스트가 온다.
 
* `cursor.fetchone()`

  * 한 줄만 튜플로 가져온다.
 
  * 여러 줄인 경우 처음 한 줄만 가져온다.
 
* 딕셔너리로 가져오기

``` python
    connect = sqlite3.connect('sqlite.db')
    connect.row_factory = sqlite3.Row
    cursor = connect.cursor()
    
    cursor.execute('''
        select deptno, dname, loc
        from dept
    ''')

    rows = cursor.fetchall()
    result = []
    for row in rows:
        result.append(dict(row)) # 컬럼명을 key로 하는 딕셔너리로 변환 가능
    print(result)

    result2 = [ dict(row) for row in rows ]
    print(result2)

    connect.close()
```

* 딕셔너리를 pydantic 클래스로 변경하기

``` python
result2 = [ DeptDTO(**dict(row)) for row in rows ]
```

#### 자동 commit 및 close 

* with를 사용해서 자동 close 실행

  * 성공하면 commit
 
  * 실패하면 rollback까지 자동
 
``` python
    # 성공하면 commit, 실패하면 rollback하고
    # close까지 자동으로 해준다
    with sqlite3.connect('sqlite.db') as connect:
        cursor = connect.cursor()

        cursor.execute('''
            update dept
            set dname = ?
        ''', ('좋은 강의실',))

        # connect.commit()
        # connect.close()
```

# pip install sqlmodel

from sqlmodel import create_engine, Session, SQLModel
from fastapi import FastAPI, Depends, Request
from fastapi.templating import Jinja2Templates
from sqlalchemy import text

# SQLModel.metadata에 등록 시킨다
# 그러면 crate_all로 테이블이 없으면 만들어 준다
# Emp3(SQLModel, table=True) 이것 둘 다 적으면 자동으로 만들어준다.
from DTO.EmpDTO import Emp3
from DTO.DeptDTO import Dept3

app = FastAPI()
templates = Jinja2Templates(directory='templates/')


# DB+driver://id:pw:@ip:port/database
DATABASE_URL = 'mysql+pymysql://root:human1234$@127.0.0.1:3306/human'
engine = create_engine(DATABASE_URL, echo=True)
# engine = create_engine(
#     DATABASE_URL, 
#     echo=True,
#     execution_options = {
#         'isolation_level' : 'AUTOCOMMIT' # rollback 안됨.
#     }
# )

def get_session():
    with Session(engine) as session : 
        yield session
        session.commit()

@app.on_event('startup')
def on_startup() :
    SQLModel.metadata.create_all(engine)

@app.get('/emp/deptno')
def emp_list_deptno(
    request: Request,
    deptno: int,
    session: Session = Depends(get_session)
):
    emp_list = []
    try:
        # text : sql문을 실행하기 전에 미리 컴파일 해둔다
        sql = text('''
            select * 
            from emp3
            where deptno = :deptno
        ''')

        result = session.execute(sql, {'deptno':deptno})
        # emp_list = result.fetchall() 
        emp_list = result.mappings().fetchall() 
        print(emp_list)
        
    except Exception as e:
        print(e)

    return templates.TemplateResponse(request, 'list.html',{
                'emp_list' : emp_list
            })

@app.get('/emp/update/sal')
def update_sal(
    per:int,
    session : Session = Depends(get_session)
):
  upsal = 1 + (per / 100) 
  print('upsal' , upsal)

  try : 
    sql = text ('''
            update emp3
            set sal = sal * :upsal
            where deptno = 30
        ''')
    result = session.execute(sql, {'upsal':upsal})
    
    print('실행 결과로 영향을 받은 row 수 :' , result.rowcount)
  except Exception as e : 
        print('ERR' , e)
        session.rollback()

if __name__ == "__main__":
    import uvicorn
    uvicorn.run("02_sqlmodel:app" , port=8000, reload=True, host="0.0.0.0")

### 🐍 EmpDTO.py

``` python
from sqlmodel import SQLModel, Field
from typing import Optional

class Emp3 (SQLModel, table=True):
    # 없으면 클래스명이 테이블명이 된다.
    # __tablename__ = "emp"

    # empno : int = Field(primary_key=True) 
    empno : int | None = Field(
        default = None,  # auto_increment
        primary_key= True
    )
    ename : str 
    job : str
    # mgr : int | None = None
    mgr : Optional[int] = None
    hiredate : str
    sal : float
    # comm : float | None = None
    comm : Optional[float] = None
    deptno : int = Field(
        foreign_key='dept3.deptno'
    )
```
