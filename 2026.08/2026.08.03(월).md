### 위치 인수 

함수에 값을 넘겨줄 때, **정해진 순서대로** 얌전하게 들어가는 인수

**주의 : 순서가 틀리면 엉뚱한 변수에 값이 들어가니까 순서를 꼭 맞추자**

### 키워드 인수 

`이름 = 값` 형태로 이름표를 딱 붙여서 넘겨주는 인수.

이름표를 붙여주면 순서를 맘대로 섞어도 알아서 자기 자리를 찾아가니까 위치가 헷갈릴 것 같으면 이걸 쓰자

### 람다 표현식 

`def`를 쓰기도 아까울 만큼 짧은 **1줄짜리 익명 함수** (`lambda 매개변수 : 표현식`)

이름도 없이 잠깐 쓰고 버릴 때만 쓰는거라서 너무 복잡한 코드를 람다로 우겨넣으면 나중에 본인도 못 알아보니까 적당히 쓰자.

``` python
# 람다 표현식
# 시스템 최적화 도구들 중에서 이름이 짧은 것만 속 골라내는 일회용 함수
tools = ['DISM', "SFC", "Geek Uninstaller", "VSCleaner"]

# 글자 수가 4글자 이하인 것만 필터링!
short_tools = list(filter(lambda x: len(x) <= 4, tools))
print(f"짧은 이름의 시스템 도구들: {short_tools}"
```

### 클로저

### 클래스

객체를 펑펑 찍어내는 설계도(틀). 흔히 붕어빵 틀에 비유.

비슷한 성질을 가진 데이터(속성)랑 기능(메서드)을 한 묶음으로 예쁘게 포장해 주는 거.

``` python
# 클래스 
# 게임 플레이어의 상태를 관리하는 툴
class HBRPlayer:
  def __init__(self, squad, playtime, chapter):
    self.squad = squad # 부대 이름  
    self.playtime = playtime # 누적 플탐 
    self.chapter = chapter # 스토리 진행도 

  def show_status(self):
    return f"소속 : {self.squad} 부대, 누적 플탐 : {self.playtime}시간, 스토리는 {self.chapter}까지 밀었어요!"

# 붕어빵 틀로 진짜 데이터들을 찍어낸 것.
my_record = HBRPlayer("31A", 20, 4)
print(my_record.show_status())

```
