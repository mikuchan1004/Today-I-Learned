### 클래스 속성

클래스 속성은 **모든 인스턴스가 공유하는 변수** 이며, `__init__` 메서드 안에서 `self.변수명`으로 만드는 '인스턴스 속성'과는 다르게 

메서드 바깥(클래스 정의 바로 아래)에 작성한다.

``` python
class Maid:
  uniform = "블랙 앤 화이트" # 이게 바로 클래스 속성. 모든 메이드 인스턴스가 이 값을 공유함.

  def __init__(self, name):
    self.name = name # 이건 인스턴스 속성이니까 각자의 이름이 다름.

m1 = Maid("렘")
m2 = Maid("람")

# 인스턴스를 거치지 않고 클래스 이름으로 바로 접근 가능!
print(Maid.uniform)
```

###  정적 메서드와 클래스 메서드 

둘 다 굳이 인스턴스를 만들지 않고도 `클래스이름.메서드` 형태로 호출할 수 있다는 건 똑같지만, 쓰임새가 완전히 다르니 헷갈리지 않게 주의.

**정적 메서드** (`@staticmethod`) : 메서드 안에서 인스턴스 속성(`self`)이나 클래스 속성(`cls`)을 전혀 쓰지 않을 때 사용.

굳이 클래스 안에 넣어둔 '일반 함수'라고 생각하면 편함.

**클래스 메서드** (`@classmethod`) : 첫 번째 매개변수로 자기 자신의 클래스(`cls`)를 무조건 받는다. 그래서 클래스 속성에 

접근해서 값을 수정하거나, 클래스 상태와 관련된 작업을 할 때 사용한다.

``` python
class TeaTime:
  tea_leaves = 100 # 클래스 속성

  @staticmethod
  def boil_water(temperature):
    # self나 cls를 받지 않는다. 
    print(f"물을 {temperature}도로 끓입니다.")

  @classmethod
  def consume_tea(cls, amount):
    # cls를 통해서 클래스 속성(tea_leaves)에 접근!
    cls.tea_leaves -= amount
    print(f"남은 찻잎 : {cls.tea_leaves}g")

# 인스턴스 생성 없이 바로 사용!
TeaTime.boil_water(90)
TeaTime.consume_tea(10)
```

###  클래스 상속

이미 잘 만들어진 부모 클래스의 기능을 물려받아 새로운 자식 클래스를 만드는 것.

부모의 메서드를 자식 입맛대로 덮어쓰는 메서드 오버라이딩(Overriding)과, 

부모의 기능을 그대로 가져다 쓰고 싶을 때 사용하는 `super()`만 잘 기억해두자.

``` python
class Master:
  def order(self):
    print("홍차를 타오도록 해라.")

# Master 클래스를 괄호 안에 넣어서 상속받는다.
class StrictMaster(Master):
  def order(self):
    # 부모(Master)의 order 기능을 먼저 그대로 실행!
    super().order()
    # 자식 클래스만의 새로운 기능을 추가(오버라이딩)!
    print("물 온도는 정확히 85도로 맞추고, 설탕은 넣지 마라!")

new_master = StrictMaster()
new_master.order()
```
