## 파이썬 클래스 전체 정리

### 클래스 

#### 객체 지향 프로그래밍 OOP

* Object Oriented Programming

* python은 객체 지향 프로그래밍 언어

* 필요할 때마다 객체를 생성하고 필요 없을 때 메모리에서 지운다.

#### 선언

``` python
class 클래스명 :
  pass
```

* 클래스명은 대문자로 시작하자.

#### 사용법

``` python
변수 = 클래스명()
```

#### 메서드 

* 클래스 안에 있는 함수를 보통 메서드라고 한다.

* 첫 번째 전달 인자 하나는 무조건 필수

  * 보통 `self`를 사용한다.

  ``` python
  class 클래스명:
    def 메서드명(self):
      pass
  ```

#### 속성

* 클래스가 가지고 있는 변수

* `self.변수명`으로 선언과 할당이 가능하다.

* 클래스 내부/외부에서 언제든 사용이 가능하다.

#### 생성자

* 메서드 명이 `__init__`인 메서드.

* 생성과 동시에 실행되는 메서드.

* 생성할 때 필수 전달 인자를 받거나 항상 실행해야 하는 내용을 적어둔다

``` python
class 클래스명:
  def __init__(self, x):
    self.x = x

a.클래스명(3) # 전달 인자는 필수
```

#### static 정적 

* 클래스를 생성하지 않고 사용 가능하다.

* 메모리의 static영역(= method 영역)에 존재하게 된다.

* self를 사용하지 못한다.

  * self는 생성된 이후에나 사용 가능하니까 (선발대 이야기를 떠올려보자)

#### 정적 속성(정적 변수)

``` python
class 클래스명:
  정적변수 = 1
```

#### 정적 메서드

``` python
class 클래스명:
  @staticmethod
  def add(x, y):
    return x + y
```

#### 변수의 종류 

* 지역 변수

  * 해당 영역(지역)에서만 사용이 가능하다.
 
  * 영역(지역)이 끝나면 메모리에서 사라진다
 
* self 변수

  * 클래스가 생성된 이후에 사용이 가능하다.
 
  * 클래스가 소멸할 때 메모리에서 사라진다
 
    * 변수가 None이 되거나 지역 변수의 역할이 끝나서 사라지거나
   
    * 변수가 다른 값으로 덮어 써질 때 (기억에서 사라질 때 죽는다)
   
* 정적 변수

  * python 종료 시 사라짐

#### 비공개 private 

* 변수나 메서드 이름 앞에 __(underscore / 언더바) 2개를 붙인다.

* 클래스 내부에서만 쓸 수 있다.

``` python
class 클래스명:
  __잔고 : 0
  def __통장개설(self, 실명인증):
    pass
```
