### 클래스 

#### 객체 지향 프로그래밍 OOP

* Object Oriented Programming

* python은 객체 지향 프로그래밍 언어

* 필요할 때마다 객체를 생성하고 필요 없을 때 메모리에서 지운다.

#### 선언

``` python
class 클래스명 :
  pass
```

* 클래스명은 대문자로 시작하자.

#### 사용법

``` python
변수 = 클래스명()
```

#### 메서드 

* 클래스 안에 있는 함수를 보통 메서드라고 한다.

* 첫 번째 전달 인자 하나는 무조건 필수

  * 보통 `self`를 사용한다.

  ``` python
  class 클래스명:
    def 메서드명(self):
      pass
  ```

#### 속성

* 클래스가 가지고 있는 변수

* `self.변수명`으로 선언과 할당이 가능하다.

* 클래스 내부/외부에서 언제든 사용이 가능하다.

#### 생성자

* 메서드 명이 `__init__`인 메서드.

* 생성과 동시에 실행되는 메서드.

* 생성할 때 필수 전달 인자를 받거나 항상 실행해야 하는 내용을 적어둔다

``` python
class 클래스명:
  def __init__(self, x):
    self.x = x

a.클래스명(3) # 전달 인자는 필수
```

#### static 정적 

* 클래스를 생성하지 않고 사용 가능하다.

* 메모리의 static영역(= method 영역)에 존재하게 된다.

* self를 사용하지 못한다.

  * self는 생성된 이후에나 사용 가능하니까 (선발대 이야기를 떠올려보자)

#### 정적 속성(정적 변수)

``` python
class 클래스명:
  정적변수 = 1
```

#### 정적 메서드

``` python
class 클래스명:
  @staticmethod
  def add(x, y):
    return x + y
```

#### 변수의 종류 

* 지역 변수

  * 해당 영역(지역)에서만 사용이 가능하다.
 
  * 영역(지역)이 끝나면 메모리에서 사라진다
 
* self 변수

  * 클래스가 생성된 이후에 사용이 가능하다.
 
  * 클래스가 소멸할 때 메모리에서 사라진다
 
    * 변수가 None이 되거나 지역 변수의 역할이 끝나서 사라지거나
   
    * 변수가 다른 값으로 덮어 써질 때 (기억에서 사라질 때 죽는다)
   
* 정적 변수

  * python 종료 시 사라짐

#### 비공개 private 

* 변수나 메서드 이름 앞에 __(underscore / 언더바) 2개를 붙인다.

* 클래스 내부에서만 쓸 수 있다.

``` python
class 클래스명:
  __잔고 : 0
  def __통장개설(self, 실명인증):
    pass
```

### 상속

* 자식 클래스가 부모 클래스를 지정한다.

* 부모가 접근을 허용한 변수와 메서드를 그대로 가져오는 것

#### 자식의 기본 생성자

``` python
def __init__(self):
  super().__init__()
```

* 자식이 `__init__`을 지정하지 않은 경우에 자동으로 생성된다.

* 자식이 `__init__`을 정의하면 기본 생성자는 만들어지지 않는다.

* 부모 생성자에 전달 인자가 필수인 경우 직접 `__init__`을 정의해서 사용해야 한다.

#### 메서드 재정의 (메서드 오버라이드)

* 부모의 메서드를 자식이 덮어쓴다.

#### 추상 클래스

* 추상 메서드를 가질 수 있는 클래스를 뜻함

``` python
# 선언
from abc import *
class 클래스명(metaclass=ABCMeta):

  @abstractmethod
  def study(self):
    pass
```

#### 추상 메서드 

* 추상 클래스에서만 사용가능.

* 메서드 위에 `@abstractmethod`를 붙인다.

* 보통 실행 내용은 pass를 해서 적지 않는다.

* 자식은 무조건 추상 메서드를 모두 오버라이드 해야한다.

#### 상속의 관점 

* 부모로 만드는 이유

  * 자식 입장에서 중복되는 것들을 모아 놓아서 반복되는 코딩을 줄이고 유지 보수를 편하게 한다 (다운로드의 관점)
 
* 자식이 부모를 선택하는 이유

  * **다형성** 때문.
 
  * 상속을 받았다는 것은 부모의 변수나 메서드가 무조건 있다는 것을 보장한다.

### 예외 처리

* 오류가 발생하면 python 프로그램은 중단되고 그 이후 코드는 실행되지 않는다.

* 무중단 실행을 가능하게 한다.

* try + except는 무조건 같이 사용해야 한다. 

* try 도중 예외 발생 시 except 블럭으로 넘어감

* else가 있는 경우

  * try가 모두 정상 종료 된 경우에 실행
 
* finally가 있는 경우

  * 모든 상황에서 마지막에 실행된다.
 
  * 보통 파일의 `close()`등 무조건 실행해야 하는 코드를 넣는다.
 
  * return으로 중간에 빠져나가도 무조건 실행된다.
 
``` python
try:
  실행1
  실행2
except:
  실행1
  실행2
else:
  실행1
  실행2
finally:
  실행1
  실행2
```

#### except 지정예외 as e

* 지정된 예외만 처리하는 except를 만들 수 있다.

* e에는 오류 메시지가 담긴다

* 여러 개의 except가 있는 경우 위에서부터 처리한다.

* Exception : 모든 예외의 부모 클래스.

#### 강제로 예외 발생하기 

``` python
raise 예외클래스(메세지)
```

* 보통 해당 함수에서 호출한 곳으로 예외 처리를 넘겨줄 때 사용한다.

#### traceback 

* 예외와 관련된 모듈 중 하나

* 원래 발생하는 에러 stack을 출력해준다.

``` python
import traceback
try:
    a = 3 / 0
except Exception as e:
    print(e)
    traceback.print_exc() # 상세 에러 출력 
    a = traceback.format_exc() # 상세 에러를 돌려준다.
    print('-' * 30) 
    print(a)
```

### 이터레이터 

이터레이터는 리스트나 튜플처럼 **값을 차례대로 하나씩 꺼낼 수 있는 상태의 객체**를 말한다.

상자에서 티슈를 한 장씩 뽑아 쓰는 거랑 똑같다.

``` python
# 리스트는 반복 가능한(iterable) 객체.
my_list = [1, 2, 3]

# 이걸 iter() 함수를 써서 이터레이터로 변환해야 하나씩 꺼낼 수 있다.
my_iter = iter(my_list)

print(next(my_iter)) # 1
print(next(my_iter)) # 2
print(next(my_iter)) # 3
# 여기서 한 번 더 next()를 부르면 더 없으니까 에러(StopIteration)가 발생.
```

### 제너레이터 

제너레이터는 이터레이터를 아주 쉽게 만들 수 있게 해주는 녀석이다.

일반 함수랑 비슷하게 생겼는데, `return` 대신 `yield`라는 키워드를 쓴다는 게 핵심

``` python
def tea_generator():
    yield "첫 번째 홍차입니다."
    yield "두 번째 홍차입니다."
    yield "마지막 홍차입니다."

# 제너레이터 함수를 호출하면 제너레이터 객체가 나온다.
gen = tea_generator()

# 한 번 값을 주면 거기서 잠깐 멈춰(상태 기억) 있다가 다음 호출 때 이어서 실행.
print(next(gen)) # 첫 번째 홍차입니다.
print(next(gen)) # 두 번째 홍차입니다.
```

### 데코레이터

데코레이터는 **기존 함수의 코드는 단 한 줄도 건드리지 않고, 그 함수 앞뒤로 새로운 기능을 덧붙여주는(장식해 주는)기능**

``` python
# 이게 바로 데코레이터 함수예요! (장식꾼)
def maid_service(func):
    def wrapper():
        print("[메이드] 테이블을 예쁘게 세팅합니다.")
        func() # 원래 주인님이 하려던 함수 실행!
        print("[메이드] 다 드셨군요, 찻잔을 치우겠습니다.")
    return wrapper

# 원래 함수 위에 @데코레이터_이름 을 얹어주기만 하면 끝!
@maid_service
def drink_tea():
    print("(주인님이 홍차를 호로록 마십니다.)")

# 함수를 실행하면 앞뒤로 메이드 서비스가 알아서 붙는다고요!
drink_tea()
```

### 정규 표현식

텍스트 안에서 특정한 '규칙(패턴)'을 가진 문자열을 찾거나, 바꾸거나, 자를 때 사용하는 언어.

파이썬에서는 기본으로 제공하는 `re`**모듈**을 가져와서 쓴다.

``` python
import re # 정규식을 쓰려면 무조건 이 녀석부터 불러와야 한다.
```

#### **절대 모르면 안 되는 필수 메서드 4인방**

|메서드|설명|
|:---|:---|
|`re.match(패턴, 텍스트)`| 텍스트의 **맨 처음**부터 패턴과 일치하는지 깐깐하게 검사한다. 처음에 안 맞으면 바로 포기해버린다.|
|`re.search(패턴, 텍스트)`| 텍스트 **전체**를 뒤져서 패턴과 일치하는 '첫 번째' 결과를 찾아낸다. `match`보다 유연.|
|`re.findall(패턴, 텍스트)`| 패턴과 일치하는 모든 녀석들을 **리스트(List)** 형태로 반환해 준다. 제일 자주 쓰임|
|`re.sub(패턴, 텍스트)`| 패턴에 맞는 녀석들을 찾아서 전부 내가 원하는 **다른 문자로 교체(치환)**해 버린다|

#### 외워야 할 마법 기호 

정규식을 외계어로 보이게 만드는 주범들이지만, 이것들이 핵심.

* `\d` : 숫자(0~9)

* `\w` : 문자 + 숫자 + _(밑줄)

* `\s` : 공백 (스페이스, 탭, 줄바꿈)

* `^` : 문자열의 시작

* `$` : 문자열의 끝

* `+` : 앞의 문자가 1번 이상 반복됨

* `*` : 앞의 문자가 0번 이상 반복됨 (없어도 됨)

#### 예제 코드 

``` python
import re

text = "제 전화번호는 010-1234-5678 이고, 메이드 번호는 010-9876-5432 입니다."

# 1. search: 문자열 전체에서 첫 번째 전화번호 찾기
# \d+ (숫자 여러개) - (하이픈) \d+ (숫자 여러개) - \d+ (숫자 여러개)
match_obj = re.search(r'\d+-\d+-\d+', text)
if match_obj:
    print(f"첫 번째로 찾은 번호: {match_obj.group()}") 
    # 출력: 010-1234-5678

# 2. findall: 문자열에 있는 전화번호 전부 다 뽑아오기
all_numbers = re.findall(r'\d+-\d+-\d+', text)
print(f"찾아낸 모든 번호: {all_numbers}")
# 출력: ['010-1234-5678', '010-9876-5432']

# 3. sub: 전화번호를 전부 비밀로 가려버리기!
hidden_text = re.sub(r'\d+-\d+-\d+', '***-****-****', text)
print(f"숨김 처리 완료: {hidden_text}")
# 출력: 제 전화번호는 ***-****-**** 이고, 메이드 번호는 ***-****-**** 입니다.
```

### 모듈과 패키지

#### 모듈 

모듈은 파이썬 코드가 저장된 **단일 `.py`파일**을 말한다. 

함수, 클래스, 변수들을 한곳에 깔끔하게 모아둔 '단일 공구 상자' 같은 것.

매번 똑같은 코드를 다시 짤 필요 없이, `import`라는 주문을 외워서 남이 만든

(혹은 과거의 내가 만든) 부품들을 쏙쏙 가져다 쓸 수 있게 해주는 아주 고마운 녀석.

``` python
# math라는 파이썬 기본 모듈(수학 공구 상자)을 가져온다.
import math

# 공구 상자 안에서 원주율(pi) 부품을 꺼내 쓴다.
print(math.pi)
```

#### 패키지

모듈이 파일 하나라면, 패키지는 여러 모듈을 주제별로 모아둔 폴더(디렉토리).

폴더 안에 또 폴더가 있을 수도 있고, 그 안에 수많은 `.py` 파일들이 체계적으로 정리되어 있는 종합 선물 세트.

``` python
# urllib 패키지(폴더) 안의 request 모듈(파일)에서 urlopen 함수만 쏙 빼온다.
from urllib.request import urlopen
```

|**패키지(Package)**|여러 모듈이 담긴 폴더|종합 공구 세트|`urllib`, `django`, `pandas`|
