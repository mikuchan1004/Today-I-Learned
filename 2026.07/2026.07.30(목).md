## 자료형

### stack과 heap

- 메모리를 효율적으로 관리하는 기법

#### stack

- 변수명과 단순한 값이나 주소가 저장된다.

- `=`을 사용하거나 전달인자로 줄 때 이 값이 전달된다.

  - `a = b : b`의 값이 `a`로 전달되는데 주소일 수도 있다.
 
#### heap

- 이미 지정된 주소에 자료가 저장된다.

#### call by reference 

- 얕은 복사라고도 한다.

- 변수에 주소만 적혀있어서 내용을 바꾸는 경우 원본도 바뀐다.

#### call by value

- 깊은 복사라고도 한다

- 값을 바꿔도 원본에 영향을 주지 않는다.

### 숫자 

- 5칙 연산

  - `+` , `-` , `*` , `/` , `%`

  - 내림이라서 음수일 때 주의 필요.

- type() : 전달인자의 자료형을 알려주는 것

- int() : 전달인자를 정수로 변환

- float() : 전달인자를 실수로 변환

### 포메팅formatting 문자열

- f"문자열 {변수} 문자열"

  - {변수} 위치에 값이 들어간다
 
  - javascript의 `(백틱)과 비슷하다.

- '문자열 %d 문자열' % 숫자

  - %d 자리에 문자열 뒤의 % 이후에 값이 들어간다.
 
  - %d (정수) , % (실수) , %s (문자열)

#### 내장 함수 (문자열)

- str() : 전달인자를 문자로 변환한다.

- len() : 전달인자의 길이를 구한다.

- .count() : 전달인자가 포함된 개수를 구해준다.

- .find()

  - 전달인자의 index를 돌려준다.
 
  - 없으면 -1을 돌려준다
 
  - 왼쪽부터 처음 만나는 index만 찾아준다.
 
  - 오른쪽부터 찾는 rfind()도 있다.
 
- .index()

  - find와 비슷하다
 
  - 전달인자가 없으면 에러
 
- .replace(전달인자1, 전달인자2) : 전달인자1을 **모두** 전달인자2로 변경한다.

- .split()

  - 전달 인자를 구분자로 하여 배열로 잘라준다.
 
  - 전달인자가 없는 경우 기본값은 띄어쓰기
 
- upper() : 모두 대문자로 변환

- lower() : 모두 소문자로 변환

> 대소문자 구분 없이 찾을 때 많이 쓴다.

- .strip()

  - 양쪽 공백을 제거한다.
 
  - 문자 중간의 공백은 유지된다.
 
  - 마치 trim 처럼

- .zfill() : 전달인자의 자리수보다 작은 경우 0으로 채워준다. (Zero fill)

### 포메팅 

- f"{a:3}"

  - a를 세자리로 출력
 
  - 남은 공백은 여백으로.
 
  - 넘치면 넘치는 대로 출력

- f"{a:3f}" : 소수점 몇 번째 자리까지 표시할지 결정

- f"{a.,}" : 3자리마다 `,` 출력

### 리스트 

- 다른 언어의 배열

- 변수의 집합.

#### 선언

``` python
a = []
a = list()
```

#### 사용 

- `a[index]`
  
  - index는 0부터 시작한다.
    
  - 음수 가능 : 음수의 경우 뒤에서부터 -1
 
#### del 

- 해당 값 제거

- `del a[0]` : 첫 번째 제거.

#### 슬라이싱 

- `리스트[시작인덱스 : 끝인덱스]`

  - 시작부터 종료 바로 앞까지 복사해준다.

- 시작인덱스를 생략하면 : 처음부터

- 종료인덱스를 생략하면 : 처음부터 끝까지

- 음수 인덱스 사용 가능

#### 내장함수 (리스트)

- append() : 배열의 마지막에 값 하나 추가

- sort() : 오름차순 정렬

  - sort(reverse=True) : 내림차순 정렬
 
- reverse() : 리스트 뒤집기

- pop() : 마지막 값을 제거하고 돌려줌

- insert(a, b)

  - a 인덱스에 b 값 하나 추가
 
  - 인덱스가 범위를 벗어나면 그냥 마지막에
 
- extend()

  - 전달인자인 리스트를 합쳐준다.
 
  - 보통 배열 + 배열로 해결한다.

- remove() : 처음 만나는 값을 찾아서 지운다 (값 없으면 에러)

- index() : 값을 찾아준다 (값이 없으면 에러)

- count() : 값이 몇 개 있는지 찾아준다.

- clear()

  - 모든 값을 지운다.
 
  - `a = []`과 같다.
 
- copy()

  - 깊은 복사한 배열을 돌려준다
 
  - 즉, copy()로 받은 값을 변경해도 원본은 유지된다.

### 딕셔너리 dict

- JSON과 비슷하고, key, value 쌍으로 값을 관리한다.

- key는 중복되지 않는다.

#### 딕셔너리 선언

``` python
a = {}
a = dict()
```

#### 사용

- `a['key']`

  - value를 돌려주며, key가 없는 경우 에러가 발생한다.
 
- `a.get('key')

  - key가 없는 경우 None을 반환
 
- a.get(key, 기본값)`

  - key가 없는 경우 기본 값 출력
 
``` python
# 2차원 값 안전하게 가져오기
b.get('스킬', {}).get('공격', 0)
```

- `a[없는key]` = 값 : key를 생성해서 값을 넣어준다

- key in 딕셔너리 : 딕셔너리에 key가 있는지 검사해서 True/False를 돌려준다.

#### 내장함수 (딕셔너리)

- len() : key의 갯수가 나온다

- keys() : key를 모두 배열로 돌려준다

- values() : value를 모두 배열로 돌려준다

- items() : key, value를 쌍으로 돌려준다.

- update(key1=value1, key2=value2) : 해당 key의 값을 변경한다.

- pop(key): key를 제거하면서 값을 돌려준다.

- fromkeys(리스트) : 리스트의 값을 key로 하는 딕셔너리 생성. 값은 None.

## 반복문 

``` python
for in 반복되는 것 :
  pass
```

- 반복되는 것의 첫번째 값이 변수에 들어가서 실행

  - 그 다음 값이 변수에 들어가서 실행하는 것을 반복한다.
 
- 딕셔너리의 경우 key가 변수에 들어간다

### range 

- 전달인자가 1개 : 0개부터 바로 앞까지

- 2개 : 앞부터 뒤 바로 앞까지

- 3개 : 첫 번째부터 두 번째 바로 앞까지 세 번씩 건너 뛰면서

  - 세번째부터 음수 가능
 
``` python
for i in range(10):
  pass
```

### 리스트 컴프리헨션 list comprehension (반복문 표현식)

- 반복문으로 리스트 만드는 코드를 압축하는 문법

``` python
a = []
for i range(10):
  a.append(i)

a = [ i for i in range(10)]
```

``` python
a = []
for i range(10):
  if i%2 == 0:
    a.append(i)

a = [ i for i in range(10) if i%2 == 0]
```

- if에 else가 있을 땐 for문 앞에 적는다.

``` python
a = [i*10 if i%2 == 0 else i for i in range(10)]
for i in range(10) :
    if i%2 == 0 :
        a.append(i*10)
    else:
        a.append(i)
```

### while 

- 반복 횟수를 모를 때 많이 사용

#### while ~ else 문 

``` python
a = 2
i = 0
while i < 10:
   if i == a:
       print('찾음')
       break
   i += 1
else : 
    print('못찾음')
```

- while 반복 동안 braak를 만나지 않고 조건식에 의해 종료되는 경우 else문이 실행 된다.
